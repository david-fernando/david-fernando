### 🧠 [SmartScraping](https://www.smartscraping.dev/)

> **Scrape data without relying on fragile selectors.**

Traditional scraping depends heavily on CSS selectors, XPath and DOM structure. When a website changes its HTML, the scraper can break.

**SmartScraping lets developers describe what data they want instead of telling the scraper exactly where to find it.**

**Focus:** `Semantic Extraction` · `LLMs` · `Web Scraping` · `REST API`
